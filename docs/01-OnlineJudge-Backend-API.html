接口总览与通用规则

基础 URL
API 前缀

所有公开接口以 /api/ 开头，管理员接口以 /api/admin/ 开头。

标准响应格式
{
    "error": null,        // 成功时为 null；失败时为错误类型字符串
    "data": ...           // 成功时为业务数据；失败时为错误消息
}
分页参数
参数类型默认值说明
limitint10每页数量（最大250）
offsetint0偏移量
认证方式

使用 Django Session + CSRF Token。前端请求需携带 Cookie 中的 csrftoken，并在 Header 中设置 X-CSRFToken。

管理员角色枚举
role值说明
REGULAR_USER-1普通用户
ADMIN1题目管理员
SUPER_ADMIN2超级管理员

一、账户模块 (account)

🔓 用户登录注册

POST/api/login/用户登录
请求体
字段类型必填说明
usernamestring是用户名
passwordstring是密码
tfa_codestring否二步验证码（开启了2FA时必填）
成功响应
{ "error": null, "data": "Succeeded" }
错误码
Invalid username or password
tfa_required
Your account has been disabled
Invalid two factor verification code
GET/api/logout/用户登出
{ "error": null, "data": null }
POST/api/register/用户注册
字段类型必填说明
usernamestring是用户名，最大32字符
passwordstring是密码，最少6字符
emailstring是邮箱地址
captchastring是图形验证码
GET/api/captcha/获取图形验证码

返回一张图片，同时 Set-Cookie 中会写入验证码相关的 session 数据。

POST/api/check_username_or_email检查用户名或邮箱是否已存在
字段类型必填说明
usernamestring否待检查的用户名
emailstring否待检查的邮箱
{
    "error": null,
    "data": { "username": false, "email": true }
}

👤 用户资料

GET/api/profile/获取用户信息

Query 参数: username (可选) — 指定用户名获取他人资料；不传则返回当前登录用户资料。

{
    "id": 1,
    "username": "admin",
    "admin_type": 2,
    "avatar": "/public/avatar/xxx.png",
    "real_name": "张三",
    "blog": "https://...",
    "github": "https://...",
    "school": "青岛大学",
    "major": "计算机",
    "language": "C++",
    "submission_number": 100,
    "accepted_number": 50,
    "total_score": 0
}
PUT/api/profile/更新用户资料需登录
字段类型必填说明
real_namestring否真实姓名
avatarstring否头像URL
blogstring否博客URL
githubstring否GitHub URL
schoolstring否学校
majorstring否专业
languagestring否偏好语言
moodstring否个性签名
POST/api/upload_avatar/上传头像需登录

Content-Type: multipart/form-data，字段 image。限制 2MB，支持格式: gif/jpg/jpeg/bmp/png。

🔐 密码管理

POST/api/change_password/修改密码需登录
字段类型必填说明
old_passwordstring是旧密码
new_passwordstring是新密码 (≥6位)
tfa_codestring否2FA验证码
POST/api/apply_reset_password/申请重置密码（发邮件）
字段类型必填说明
emailstring是注册邮箱
captchastring是图形验证码

同一邮箱 20 分钟内只能申请一次。

POST/api/reset_password/确认重置密码
字段类型必填说明
tokenstring是邮件中的重置token
passwordstring是新密码
captchastring是图形验证码
POST/api/change_email/修改邮箱需登录
字段类型必填说明
passwordstring是当前密码
new_emailstring是新邮箱
tfa_codestring否2FA验证码

🛡️ 二步验证 (2FA)

GET/api/two_factor_auth/获取2FA二维码需登录
{ "error": null, "data": "" }
POST/api/two_factor_auth/开启2FA需登录
字段类型必填说明
codeinteger是TOTP验证码
PUT/api/two_factor_auth/关闭2FA需登录
字段类型必填说明
codeinteger是TOTP验证码
POST/api/tfa_required/检查某用户是否开启2FA
{ "error": null, "data": { "result": true } }

三、题目模块 (problem)

GET/api/problem/tags/题目标签列表

Query: keyword (可选)

[
    { "id": 1, "name": "DP", "problem_count": 5 },
    { "id": 2, "name": "图论", "problem_count": 10 }
]
GET/api/problem/题目列表 / 题目详情
作为列表（无 problem_id 时）
参数类型说明
limitint是
offsetint偏移量
tagstring按标签筛选
keywordstring标题/ID 关键词
difficultystring难度等级
作为详情（有 problem_id 时）

Query: problem_id — 题目的 Display ID（字符串）

{
    "id": 1,
    "_id": "1001",
    "title": "A+B Problem",
    "description": "....",
    "input_description": "...",
    "output_description": "...",
    "time_limit": 1000,
    "memory_limit": 256,
    "rule_type": "ACM",
    "difficulty": "Mid",
    "tags": ["入门"],
    "samples": [{"input": "1 2", "output": "3"}],
    "languages": ["C++", "Python3"],
    "template": { "C++": "#include ..." },
    "my_status": "ac"
}
GET/api/pickone/随机抽取一道公开题目
{ "error": null, "data": "1001" }
GET/api/contest/problem/比赛题目列表 / 详情
参数类型说明
contest_idint比赛ID（列表时需要）
problem_idstring题目 Display ID（详情时）

比赛未开始或封榜后，普通用户只能获取安全信息（不含样例、描述等）。

GET/api/contests/比赛列表
参数类型说明

rule_typestringacm 或 oi
statusstringnot_start / underway / ended
GET/api/contest/比赛详情

Query: id (int)

{

POST/api/contest/password/密码验证需登录
字段类型必填说明
contest_idint是比赛ID
passwordstring是比赛密码
{ "error": null, "data": true }
GET/api/contest/access/检查当前用户是否可进入比赛需登录
{ "error": null, "data": { "access": true } }
GET/api/contest/announcement/比赛公告列表
参数类型说明
contest_idint是
max_idint增量拉取用
GET/api/contest_rank/比赛排行榜
参数类型说明
contest_idint是（通过查询string self.contest获取）
download_csvstring值为"1"时返回xlsx文件
force_refreshstring管理员可用，强制刷新缓存

排行榜有缓存。ACM 规则返回 accepted_number、total_time 等；OI 规则返回 total_score。

五、提交模块 (submission)

POST/api/submission/提交代码需登录
字段类型必填说明
problem_idint是题目数据库ID
languagestring是语言名称（如 C++、Python3）
codestring是源代码 (≤1MB)
contest_idint否比赛ID（比赛中提交）
captchastring否图形验证码
{ "error": null, "data": { "submission_id": 12345 } }

提交限流采用令牌桶策略，用户默认 5 秒一次。

GET/api/submission/提交详情需登录

Query: id (int)

{
    "id": 12345,
    "user_id": 1,
    "username": "admin",
    "problem": 1,
    "language": "C++",
    "code": "#include...",
    "result": 0,
    "statistic_info": {
        "0": {"cpu_time": 10, "memory": 262144, "result": 0}
    },
    "create_time": "2026-10-26 10:00:00",
    "shared": false
}
PUT/api/submission/分享/取消分享提交需登录
字段类型必填说明
idstring是提交ID
sharedbool是是否公开
GET/api/submissions/提交列表
参数类型说明
limitint是
offsetint偏移量
problem_idstring题目 Display ID
myselfstring"1" 只看自己
resultint按结果筛选
usernamestring按用户名筛选

此接口不接受 contest_id，比赛提交请用 contest_submissions。

GET/api/contest_submissions/比赛提交列表

参数 submissions 类似，另自动关联当前比赛。

GET/api/submission_exists/判断当前用户是否对某题有提交
{ "error": null, "data": true }

字段类型说明
actionstring"heartbeat"
hostnamestring主机名
judger_versionstringJudger 版本
cpu_coreintCPU 核数
cpufloatCPU 使用率 %
memoryfloat内存使用率 %
service_urlstring服务URL

八、管理员专属接口总览 (/api/admin/*)

以下所有接口需要 super_admin_required 或 problem_permission_required 装饰器保护，仅限管理员角色访问。

👥 用户管理

方法路径说明
GET/api/admin/user/用户列表（支持 keyword 搜索、id 查询、分页）
POST/api/admin/user/批量导入用户 users: [[username, password, email, real_name], ...]
PUT/api/admin/user/编辑用户（含 admin_type、problem_permission、open_api、2FA、禁用等）
DELETE/api/admin/user/批量删除用户 ?id=1,2,3
GET/api/admin/generate_user/下载批量生成用户的 Excel ?file_id=xxx
POST/api/admin/generate_user/批量生成账号（prefix + number_from..number_to + suffix）

📢 公告管理

方法路径说明
GET/api/admin/announcement/公告列表/详情
POST/api/admin/announcement/创建公告 (title, content, visible)

DELETE/api/admin/announcement/删除公告

📝 题目管理
