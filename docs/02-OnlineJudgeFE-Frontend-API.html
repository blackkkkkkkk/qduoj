⚠️ 前端特有的错误处理

场景行为
后端返回 error !== nullVue.prototype.$error(data) 弹窗 + Promise reject
错误消息以 Please login 开头OJ 端触发登录弹窗；Admin 端 router.push('login')
网络/Server 异常Vue.prototype.$error(res.data.data) + Promise reject
